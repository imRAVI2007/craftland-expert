# Script copy policy and index

No original FC script is modified or copied into this repository. The original project source paths and the extracted 63-entry declaration index are in [knowledge/scripting/fc-script-index.md](../../knowledge/scripting/fc-script-index.md).

A reusable copy may be added to `scripts/by-category/` only after checking the code itself, understanding its purpose, dependencies and behavior, recording limitations, confirming it contains no secret/private project identifiers, and considering source redistribution rights. The extracted 04 index explicitly says it does not paraphrase every branch; therefore it cannot alone establish that an implementation is standalone and safe to reuse. Current reusable source-copy count: **0**.
